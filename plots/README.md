# Plots

Figure numbers match the 2026-08-03 revision of the manuscript. See the [Plots section of the main README](/README.md#plots) for what each figure shows and which script produces it.

- `figureX_nocaption.pdf`: the figure as submitted to the journal
- `figureX.pdf`: the same figure with its caption underneath

Figure S5 (non-imputed pollen data) is not generated by this repository yet.

The `.png` files are older previews and may not match the current PDFs. They can be regenerated from the PDFs with [ImageMagick](https://imagemagick.org/index.php), for example `magick -density 150 figure2.pdf figure2.png`.
